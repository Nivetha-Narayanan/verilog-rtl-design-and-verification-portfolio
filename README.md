# verilog-rtl-design-and-verification-portfolio
A continuously growing Verilog-based RTL design and functional verification portfolio focused on digital design fundamentals, industry-style workflows, and FPGA-oriented synthesis using Xilinx Vivado.  

## RTL Design and Verification
Welcome to my hardware engineering repository. This space serves as a professional log of my journey into RTL (Register Transfer Level) Design and Verification.
​Rather than just writing code, I use this repository to document the "Hardware Mindset"—the transition from sequential software thinking to the concurrent, timing-driven world of Digital VLSI.      

## Objective
​I am building an industry-standard skillset in RTL Design, Functional Verification, and Digital Synthesis. This repository tracks my daily routine of implementing hardware architectures, starting from fundamental logic to complex system components.  
## Tools & Environment
-  **HDL:** Verilog. 
-  **Design Suite:** Xilinx Vivado (Elaboration & Synthesis). 
-  **Simulation:** Vivado Simulator / Icarus Verilog. 
 - **Waveform Analysis:** Vivado Waveform Viewer / GTKWave.
